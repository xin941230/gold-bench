# 黄金交易心理与策略工作台

一个面向 XAUUSD（现货黄金/黄金CFD）新手交易者的单页学习与实践工作台。

## 功能

- **智能问答台**：实时联网金价查询 + 交易知识问答（斐波纳奇、阴阳烛形态、支撑阻力、止损仓位、交易心理）
- **阴阳烛学堂**：K线四价解剖、12种经典形态图库（自动绘制蜡烛图）、8题看图测验
- **交易心理实验室**：损失厌恶（前景理论）、七大心理偏误对策、情绪温度计
- **斐波纳奇计算器**：回调位+扩展位，黄金口袋高亮
- **仓位与策略**：本金自定义（localStorage 持久化），五档账户策略卡，仓位风险计算器
- **开仓前自检**：8项强制检查清单

## 使用

纯静态单文件，直接用浏览器打开 `index.html` 即可，无需构建、无需后端。

实时金价数据来自公开免费接口（gold-api.com），可能有延迟。
